# Система оповіщення

Це система оповіщення, яку ми розвиваємо на практичних заняттях. Оператор створює оповіщення, система
показує його на екрані й рахує термінові. На занятті 3 ми напишемо перші функції системи так, щоб їх
перевіряли автоматичні тести.

## Як запустити

**У браузері, на JSFiddle.** Першу половину заняття ми працюємо в JSFiddle, за посиланням, яке дасть
викладач. Панель JavaScript містить код системи, тобто файл `src/alerts.js`. Тести fiddle бере з цього
репозиторію, з файлу `tests/alerts.spec.js`: це той самий файл, що й у вас після клонування. Код тестів
можна переглянути в результатах, натиснувши «Показати код тестів». Після кожної зміни коду натисніть
Run, і тести запустяться знову.

**На власному комп'ютері.** Потрібні Node.js (версія 22 або новіша) і Git. Створіть свій репозиторій
із шаблону (*Use this template*), клонуйте його, скопіюйте весь вміст панелі JavaScript із fiddle у файл
`src/alerts.js` і виконайте:

```bash
npm install    # один раз: встановлює Vitest
npm test       # запускає тести і перезапускає їх після кожного збереження файлу
```

Щоб зупинити тести, натисніть `q` або `Ctrl+C`.

## Що де лежить

| Файл | Що в ньому |
|---|---|
| `src/alerts.js` | код системи: тут ви пишете функції |
| `tests/alerts.spec.js` | тести, які ми разом зробимо зеленими на занятті |
| `cards/` | тести карток: кожен студент переносить до `tests/` файл своєї картки |
| `index.html`, `runner.js` | ті самі тести в браузері, без Node: сторінку відкривають через будь-який вебсервер |

## Правила роботи

1. **Тести не змінюються.** Тест є специфікацією: він записує, що функція обіцяє робити. Якщо тест
   червоний, змінюється код у `src/alerts.js`, а не тест.
2. **Червоне → зелене → рефакторинг.** Спочатку тест червоний. Далі пишемо найпростіший код, з яким він
   стає зеленим. Потім покращуємо код, а тести тим часом стежать, щоб поведінка не змінилася.
3. **Коміт після кожного зеленого кроку.** Коли всі тести зелені, зробіть коміт і опишіть, що саме
   зроблено: `git add .`, `git commit -m "…"` і `git push`.
